# Bike Planet

Минимальный планировщик велосипедных маршрутов с учётом рельефа. Можно построить маршрут между точками A и B или кольцо заданной длины с возвращением к старту.

## Что есть в MVP

- карта OpenStreetMap на MapLibre;
- маршруты A → B и кольцевые маршруты длиной 5–100 км;
- режимы Direct, Balanced и Flattest;
- ограничение максимального крюка для Flattest (30% по умолчанию);
- штраф за участки круче выбранного комфортного уклона;
- 2–3 варианта на карте, расстояние, время, набор высоты, максимальный и типичный уклон;
- профиль высоты выбранного маршрута;
- bicycle-only low-stress routing с исключением highways;
- Next.js/TypeScript/Tailwind и self-hosted Valhalla в Docker Compose.

## Запуск

Нужны Node.js 26, Corepack, Docker и Docker Compose. Для разработки Next.js запускается локально, а Valhalla — в Docker:

```bash
docker compose up -d valhalla
corepack pnpm install
corepack pnpm dev
```

Откройте [http://localhost:3000](http://localhost:3000). При первом запуске Valhalla скачивает OSM-данные Португалии, строит граф и загружает высоты — маршруты начнут строиться после завершения этой подготовки. Прогресс виден так:

```bash
docker compose logs -f valhalla
```

Чтобы использовать другой регион, скопируйте `.env.example` в `.env` и замените `OSM_PBF_URL` на URL нужного `.osm.pbf`-экстракта Geofabrik. После смены региона потребуется пересоздать том данных Valhalla.

Полный стек также описан в `docker-compose.yml`, если понадобится контейнерный запуск приложения.

Локальный backend по умолчанию обращается к Valhalla на `http://localhost:8002`.

Проект использует pnpm через Corepack, TypeScript 7 и Biome. Проверка форматирования и кода запускается командой `pnpm check`.

## Как выбирается маршрут

Backend запрашивает велосипедные маршруты с разной чувствительностью к холмам (`use_hills`), минимальной склонностью к обычным автомобильным дорогам (`use_roads: 0`) и жёстким исключением highways. Профиль получается через Valhalla `/height`, после чего метрики пересчитываются на равномерных 75-метровых сегментах. Direct выбирает кратчайший вариант, Balanced учитывает расстояние, набор и крутые участки, Flattest выбирает минимально сложный по рельефу маршрут только среди вариантов, укладывающихся в заданный максимальный крюк.

Для кольца backend генерирует несколько направлений с двумя промежуточными точками, строит черновые замкнутые маршруты, корректирует их радиус по фактической длине и возвращает варианты, ближайшие к заданной дистанции. Balanced и Flattest дополнительно учитывают набор высоты и слишком крутые сегменты.
